Project question

Scopeify inspects bounded CSV, TSV, text, JSON, JSON Lines, and spreadsheet structure in this browser. Cell values stay local. Only filenames, sheet and field names, inferred types and roles, derived counts, and review flags are sent for scoping. H5AD, RDS, Parquet, and Feather files are identified but require format-specific review.

Production method

  • The private backend validates the table preview, source plan, SOW draft, and workbook rows against typed schemas before anything client-facing is rendered.
  • PubMed, GEO, SRA, ENA, GSA/CNSA, and bioRxiv discovery calls run server-side with source-specific queries, bounded results, and provenance.
  • Pydantic AI can revise the typed SOW when enabled, but the public page keeps a cost-safe validated SOW path available.
