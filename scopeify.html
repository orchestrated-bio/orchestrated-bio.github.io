Project question

Demo scans small CSV, TSV, TXT, and JSON files in your browser for filenames, formats, headings, primitive types, missingness, candidate design fields, and preview-level risks. Production Scopeify would validate that structured DataPreview before sending approved summaries to a small backend LLM for scoping review.

Production method

  • The private backend validates the table preview, source plan, SOW draft, and workbook rows against typed schemas before anything client-facing is rendered.
  • PubMed, GEO, and SRA calls run server-side first; ENA, GSA/CNSA, and bioRxiv remain planned adapters until their metadata paths are validated.
  • Pydantic AI can revise the typed SOW when enabled, but the public page keeps a cost-safe validated SOW path available.
