Building Insight: From PhD Thesis to Cancer Genomics Platform

How a frustrated researcher’s side project became a conversational platform for TCGA cancer data.

AN

Alex Nesta, PhDFounder and Chief Technology Officer

During my PhD, I spent countless hours writing custom R scripts just to answer basic questions about TCGA cancer data. “What’s the survival difference between TP53 mutant and wild-type patients in BRCA?” should have been a quick lookup. Instead, it was a multi-hour scripting exercise involving data download, parsing, filtering, survival analysis, and visualization.

That frustration planted the seed for what would become Insight, a platform where you type a question in plain English and get an answer with publication-quality figures in seconds.

The problem

TCGA is one of the most valuable public datasets in cancer research: multi-omic data for 33 cancer types across more than 11,000 patients. But accessing it programmatically means understanding the data model, writing API calls, merging disparate tables on patient barcodes, applying the right statistical methods, and generating interpretable visualizations.

In my own work the wrangling reliably took longer than the analysis: pulling the data, reconciling barcodes across assays, and getting to a matched cohort before a single statistical question could be asked. Insight exists to collapse that first part.

What we built

Insight is not a chatbot with a database connection. You ask a question in natural language; the system selects the cohort, runs the analysis in a separate computation layer, and returns the result with its methods, denominators, and limits attached.

The split matters: the model reads the question and writes the explanation, but every number comes out of the computation layer. The model does not produce figures from memory, so a wrong answer looks like a wrong query rather than a plausible fabrication.

If you’re a researcher tired of writing boilerplate code to ask basic questions about cancer data, try Insight. If you’re an engineer building AI for science, I hope this series gives you some useful patterns to steal.
